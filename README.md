# 考研英语阅读逐句精翻实训与智能单词本平台 (2010–2026)

> 面向全国硕士研究生招生考试（英语一 / 英语二）考生的开源在线精读、逐句翻译实训与生词复盘平台。纯前端驱动、按需分片秒开、本地数据隐私保障。

---

## 🌟 核心特色与架构优势

1. **全真题库完整收录（2010–2026）**
   - 完整涵盖全国硕士研究生招生考试英语（一）与英语（二）共 **34 套试卷、136 篇阅读（Text 1–4）、近 3,000 个长难句、680 道真题** 原文、逐句语块切分、选项解析与逻辑导图。
2. **按需分片秒开（Dynamic Chunking）**
   - 摒弃以往一次性下载 6MB+ 题库的单体模式，采用轻量清单（Manifest，约 28KB）与按年分片数据（单年约 30KB Gzip）。首屏流量消耗**削减 98%**，弱网与移动端秒级呈现。
3. **纯前端本地智能算法（Zero-Backend）**
   - 打分比对、语块切分命中率计算、语法结构诊断与错题收集全部在客户端浏览器本地执行。零远程服务器计算，零网络延迟，抗并发能力极强。
4. **数据隐私与防丢失机制（LocalStorage + JSON 备份）**
   - **零个人信息采集**：无注册登录、无云端数据库、无第三方追踪探针。
   - **双重备份**：浏览器本地自动保存答题进度与生词本，同时支持**一键导出 JSON 备份**与**本地导入恢复**，跨设备迁移做题记录零门槛。
5. **四维联动学习工作区**
   - **01 逐句精翻实训**：沉浸式逐句输入自译文本，实时展示语块得分、核心词汇捕捉与句法结构点拨。
   - **02 篇章逻辑导图**：段落大意提炼、篇章论证脉络梳理。
   - **03 真题选项精析**：题干定位句追溯、干扰项特征精准剖析。
   - **04 单词与句型本**：智能收集弱项词汇与长难句型，支持标记已掌握，内置标准 A4 打印样式，一键导出高清复习 PDF。
6. **跨端响应式交互体验**
   - 适配桌面宽屏双栏布局与手机端竖屏单手操作；移动端支持下滑自动隐藏顶栏，最大化利用屏幕阅读空间。

## 🚀 快速开始

### 方式一：在线体验（推荐）

直接访问已部署的 GitHub Pages 站点：
👉 [https://eastorie.github.io/kaoyan-reading-jingfan/](https://eastorie.github.io/kaoyan-reading-jingfan/)

### 方式二：本地运行

本项目为标准静态 Web 应用，无需安装复杂后端环境。克隆仓库后启动任意静态 HTTP 服务器即可：

```bash
# 1. 克隆仓库
git clone https://github.com/Eastorie/kaoyan-reading-jingfan.git
cd kaoyan-reading-jingfan

# 2. 使用内置轻量服务器启动
python3 server.py
# 或者使用 Python 原生模块：
# python3 -m http.server 8000

# 3. 浏览器访问
# http://127.0.0.1:8765/index.html
```

## 🛠 数据分片与维护说明

如果更新了 `jingfan_bank.json` 中的题目或解析，可通过以下命令重新自动生成分片数据：

```bash
python3 build_data.py --split
```

该命令会读取全局题库并自动切分输出至 `data/chunks/` 目录并刷新 `data/manifest.json` 清单。
