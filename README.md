# 考研英语（二）阅读逐句精翻实训与智能单词本系统 (2015–2026)

专为考研英语（二）考生打造的高效在线逐句翻译实训与题源复盘平台。

## 核心功能
1. **全真题库覆盖**：完整收录 2015–2026 年（共 12 年、48 篇阅读 Text 1–4、898 句、240 题）真题原文与精翻对照。
2. **逐句翻译实训**：英文原文下方即时输入个人译文，提交后即刻呈现逐语块切分采分点、语法逻辑点拨与参考标准精译。
3. **整篇综合打分与诊断**：支持整篇交卷评分（0–100 分）、等级判定（S/A/B/C 级）及语块、词汇、句型三维诊断。
4. **错题单词与句型本**：自动将未译出、翻译偏差的核心词汇与长难句型汇集入本，支持单条收藏、掌握标记与自定义添加。
5. **A4 复习 PDF 导出**：支持一键导出排版严整的错题复盘本 PDF。
6. **全终端自适应**：手机端与电脑端完美自适应。

## 本地启动
```bash
python3 server.py
# 访问 http://127.0.0.1:8765/index.html
```
